Fundamentos físicos y matemáticos
=================================

Esta sección describe los fenómenos físicos que motivan los componentes de
KineSIM. Las ecuaciones deben interpretarse de acuerdo con el nivel de
aproximación de la implementación: el proyecto no es un simulador atomístico.
